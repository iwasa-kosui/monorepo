## テストを実行する

「テストを実行する」を押します。

実行すると、4件が成功して4件が失敗します。ここでは失敗して正常です。実行欄には、件数と失敗したテストが出ます。`pass 4 / fail 4` の行は、実行欄の結果の一番上に出ます。

成功した4件は、既存の業務が動いていることを示します。失敗した4件は、第2章で書くコードがまだ無いので失敗しています。「キャンセルした人と理由を答えられる」が成功すれば、問い合わせに答えられます。

<summary>出力例を見る</summary>

成功したテストも含めて手元の Node で実行すると、次の形で出ます。

```text
▶ 既存の業務
  ✔ 予約した来院をキャンセルすると、来院の状態がキャンセルになる
  ✔ 診察が終わった来院はキャンセルできない
  ✔ キャンセルできなかったときは、記録を残さない
  ✔ 来院の更新に失敗したら、記録も残らない
▶ 第2章 ステップ1
  ✖ 来院をキャンセルすると、来院キャンセルの記録が1行残る
  ✖ キャンセルの記録に、キャンセル後の来院の状態が残る
  ✖ 記録に失敗したら、来院のキャンセルも失敗する
▶ 第2章 ステップ2
  ✖ キャンセルした人と理由を答えられる
ℹ pass 4
ℹ fail 4
```

<details>
<summary>手元の Node で動かすとき</summary>

同じディレクトリで、次のコマンドを実行します。

```bash
node --test visits.test.ts
```

`ℹ pass` と `ℹ fail` の行は失敗の詳細の上に出ます。画面を上に戻して確かめます。
