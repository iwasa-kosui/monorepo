```text
┌─────────┬────────────────────────────┬────────────────────────────┬─────────────────────────────────────────────┐
│ (index) │ requestedAt                │ finishedAt                 │ message                                     │
├─────────┼────────────────────────────┼────────────────────────────┼─────────────────────────────────────────────┤
│ 0       │ '2026-11-06T10:14:12.720Z' │ '2026-11-06T10:14:12.720Z' │ { visitId: 'visit-1', petName: 'ポチ' }     │
```
