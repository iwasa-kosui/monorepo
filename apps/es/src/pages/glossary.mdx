# 用語

この教材に出てくる言葉を、初めて出てくる章の順に並べます。各章の本文でも、言葉が初めて出てくる箇所で同じ意味を書いています。

| 用語 | 意味 | 初めて出てくる章 |
|---|---|---|
| 実行欄 | ページの中でコードや SQL を実行する欄です。 | 第1章 |
| 開始コード | 演習を始める時点のコードです。ステップ1は `chapter-1-start`、ステップ2は `chapter-2-step-2-start` にあります。 | 第1章 |
| ADR | 設計上の決定を残す文書です。状況、決定、結果、代替案の順に書きます。 | 第2章 |
| `visit_cancellations` | 来院のキャンセルを1件1行で残すテーブルです。ステップ1の開始時点の DB に用意してあります。 | 第2章 |
| 業務イベント | 業務で起きた1つの出来事を、誰が、いつ、何を、なぜとともに残す記録です。 | 第2章 |
| `business_events` | 業務イベントを1件1行で残すテーブルです。ステップ2の開始時点の DB に用意してあります。 | 第2章 |
| トランザクション | 複数の更新をまとめて、すべて成功させるか、すべて取り消すかにする DB の仕組みです。 | 第2章 |
| 完成コード | 演習を終えた時点のコードです。ステップ1は `chapter-2-step-1`、ステップ2は `chapter-2-step-2` にあります。 | 第2章 |
| `payload` | `business_events` の列の1つです。操作した人や理由など、業務の情報を JSON で入れます。 | 第2章 |
| `target_state` | `business_events` の列の1つです。変更後の来院の行を JSON で入れます。 | 第2章 |
| パターン | 業務イベントの記録を既存のシステムに足す場面の例です。集計テーブル、外部システム同期、既存の監査ログの3つがあります。 | 第4章 |
| 判断表 | 3つのパターンを同じ観点で並べた表です。第1章で挙げた問いに近いパターンを選ぶときに使います。 | 第4章 |
| 読み取り関数 | 業務イベントを読んで問いに答える関数です。 | 第4章 |
